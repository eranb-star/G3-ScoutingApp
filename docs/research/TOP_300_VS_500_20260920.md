## What was actually retrieved

Ten public Statbotics v3 team_years requests, one per year, returned HTTP 500. Saved in `ranked-corpus-20260920.json`. Failure is not evidence of zero teams. No repeated polling was installed.

Fallback: official Statbotics CSV archive, linked from the Statbotics repository. Retrieved complete v3/team_years.csv (21,706,187 bytes) at commit `02113df5bc7c66655fd0496ead62ad4fc5212283`. Public source: https://github.com/avgupta456/statbotics-csvs/tree/02113df5bc7c66655fd0496ead62ad4fc5212283 . Local CSV `statbotics-team-years.csv`; repository tree `statbotics-archive-tree.json`; selected IDs `ranked-selection-analysis.json`.

Method: parse quoted CSV fields; require positive team number, `offseason=f`, positive played-match `count`, and non-null EPA. Order EPA descending, team number ascending as deterministic tie-break. This is a snapshot selection, not a claim to reproduce the current website's official tie handling. Excludes teams with only preseason estimates or offseason participation.

## Source inventory limitation

Ranking rows contain competition statistics, not inventories of CAD, build logs, technical binders, code or video. Therefore obtaining the ranked list alone cannot establish engineering document counts. No complete document census for either selection has been completed. FIRST's previously counted 380 archive URLs and current WPILib documentation are independent of this team cutoff and should remain included.

## Decision and remaining work

Keep 500 as the provisional scope. Current Supabase disk usage (0.34 GB of 8 GB, separately inspected) does not justify excluding teams ranked 301–500. 300 remains a valid fallback for measured processing/review workload, not an assumed storage necessity.

Before final selection:
1. Obtain a trustworthy 2024–2026 ranking snapshot or a restored official endpoint. Choose and record season cutoff (regular season versus offseason); current-season ranks remain dated snapshots.
2. Define the unranked 2021 treatment explicitly: carry over documented 2020/2021 designs and include by available evidence, without calling this an EPA top 300/500.
3. Enumerate source URLs for selected team-seasons, deduplicating shared sources and document versions. Report source types, unreachable/private links and total bytes separately. Compare ranks 1–300 against 301–500 directly.
4. Count useful evidence only after representative extraction, with measured yield and review effort. Any full-corpus projection must be labelled an estimate.
5. Choose 300 only if the additional 200 per season costs materially more than its useful coverage. Preserve Team 6740, strong documented exceptions, on-request additions and general engineering references under either option.
