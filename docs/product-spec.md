# G3 Scouting System – Product Spec (v1.0)

## Goals
- Android + iOS mobile scouting app
- Offline-first + auto-sync
- Web dashboard for strategy/mentors (analytics + picklist + simulator)
- 20–40 concurrent users

## Roles
- SCOUT
- STRATEGY (strategy team + mentors)

## Principles
- Write locally first
- Append-only server storage
- No text during match; notes only post-match
- Event-based data (import from TBA)
