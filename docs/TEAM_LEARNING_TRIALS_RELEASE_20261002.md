## Improvement flow
Skills Academy → Shared robot tests (also linked from Robot reliability) → define setup or select existing reliability plan → record repeated trials manually/import CSV → review → save. Saved setup/results are immutable. Retest and correction append records referencing the original. Link a failed test to an existing Work task; record the repair/change before retesting. No duplicate task system.

Protocols cover CAN faults, intake/jams, shooting and autonomous completion. Physical and simulated results are labeled and cannot be used interchangeably as baselines. Setup includes robot/mechanism, code revision if known, battery, conditions, procedure, pass criterion and units. Comparison shows sample size, counts, success rate, duration mean/sample deviation/range and throughput; differences in conditions are explicit. These are observed statistics, not causal or safety certification. Automatic robot log ingestion remains a later phase.
