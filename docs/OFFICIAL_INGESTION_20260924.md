## Delivered design

- Admin Check now discovers year-specific FIRST-hosted PDF/HTML links from configured season materials/playing-field pages. Configure a future season through the existing UI. No scheduler or frequent polling, no AI extraction charge.
- PDFs are downloaded once into private temporary Storage and extracted in batches of eight pages per leased request; durable staging is published only when complete. Temporary bytes are removed after success/failure; cancelled or interrupted jobs are cleaned on subsequent user checks (24-hour inactivity cutoff, no background polling). Two repeated resource failures stop that page batch with an explicit error. One bounded HTML document per request; previous indexed revisions use HTTP validators. Unindexed/failed fingerprints are downloaded again so a 304 cannot prevent first ingestion. Existing resume, cancellation and failed-item retry remain.
- Pinned unpdf 1.4.0 extracts PDF text with original page locators; HTML uses heading/anchor locators. No PDF scripts, OCR, images or CAD interpretation. Bounds: 24 MB PDF, 128 MB per check, 80 documents, 250 PDF pages, 1.5 million extracted characters and 1,500 passages per document. Unsupported, image-heavy and failed documents are explicit attention items. Blank/diagram pages can be absent from text; consult originals for visual/table interpretation.
- Atomic service-only publication validates lease, records fingerprint/version, retires earlier corpus copies of the same URL and publishes all extracted chunks into the existing active generation. Failure after a changed valid response retires old indexed text rather than presenting it as current. Old versions/citations are retained. Repeat publication of a hash does not duplicate citations; counts reconcile with the generation contract. A pre-collected same-hash source is upgraded with page-linked citations once, preserving legacy citations. Official retrieval uses the current extractor output, not old unlocated snippets.
- Search/selected-evidence resolution reuse existing RPCs and permissions. G3 Assist ranks distinct query concepts, keeps adjacent pages with the highest-ranked manual excerpts, deduplicates exact passages and retrieves at most six manual plus two supplemental excerpts; the existing live 2026 HTML fallback remains. English canonical manuals are authoritative for rule retrieval; translated manuals remain searchable. Missing future evidence is an explicit retrieval gap, not proof that the game is unreleased.
- UI distinguishes indexed passages from unindexed documents and reviewed interpretations. Search links retain season/source filters. Software Mentor code selection and question now share one compact composer, as accepted by the user.

### Lessons that constrain the next increment

Do not declare a release complete from a build or a fingerprint count. Verify a real question against the exact retrieved passages, citations, persisted history and settled ledger. A page containing “see next table” requires adjoining context. Same bytes in a legacy source do not imply the current extractor/locator contract is satisfied. Keep strict evidence bounds while tolerating legitimate citation formatting. Keep repository selection, question and Send in one clear flow; selecting code is not a paid request. Distinguish source links, indexed text and mentor-reviewed claims in every status report.
